# Mo‘jiza 777 — Premium Confectionery & Catering Frontend

Qarshi shahridagi **«Mo‘jiza 777»** qandolat uyi uchun zamonaviy, tezkor va hashamatli veb-platforma frontend qismi.

---

## 🚀 Texnologiyalar steki

* **Framework:** Next.js 15 (App Router, Server & Client Components)
* **Kutubxona:** React 19
* **Dizayn & Stillar:** Tailwind CSS, Framer Motion animatsiyalari, Lucide Icons
* **Xalqaro interfeys (i18n):** `next-intl` (O‘zbek va Rus tillari)
* **Form & Validatsiya:** React Hook Form, Zod
* **Holat boshqaruvi (State):** Zustand, TanStack React Query

---

## ✨ Asosiy imkoniyatlar

1. **🛍️ Jonli Katalog va Savat:**
   * Mahsulotlarni vaznli (kg) va donali hisoblash.
   * Minimal buyurtma summasi va bepul yetkazish chegarasini real vaqtda hisoblash.
   * Ro‘yxatdan o‘tmasdan tezkor buyurtma (Guest Checkout).

2. **🎂 Interaktiv Tort Konstruktori (Cake Builder):**
   * Qavatlar, biskvitlar, kremlar, mevalar va bezaklarni mijozning o‘zi tanlashi.
   * Jonli narx kalkulyatori va maxsus istaklarni kiritish.

3. **💍 To‘y va Marosimlar (Catering):**
   * To‘y oqshomi, Fotiha, Banket va Yubileylar uchun katta buyurtmalar qabul qilish.
   * Pishiriqlar, tandir somsa, chuchvara va shohona to‘y tortlari buyurtmasi.

4. **👑 Admin va Operator (Staff) Boshqaruv Paneli:**
   * Buyurtmalarni real vaqt rejimida qabul qilish va holatini o‘zgartirish (Ovozli bildirishnoma bilan).
   * To‘y va marosim arizalarini ko‘rish va qayta ishlash.
   * Mahsulotlar vitrinasi, aksiyalar va toifalarni boshqarish.
   * Xavfsizlik: Rolga asoslangan kirish (ADMIN vs STAFF).

5. **📱 Mobile-First Responsive Dizayn:**
   * Smartfonlar, planshetlar va kompyuterlar uchun 100% moslashtirilgan.

---

## 🛠️ O‘rnatish va ishga tushirish

```bash
# 1. Kutubxonalarni o‘rnatish
npm install

# 2. Rivojlantirish rejimida ishga tushirish
npm run dev

# 3. Production build qilish
npm run build

# 4. Production rejimida ishga tushirish
npm run start

# 5. Linter tekshiruvi
npm run lint
```

## 🔒 Xavfsizlik

* Content Security Policy (CSP), X-Frame-Options, X-Content-Type-Options himoyasi.
* Xavfsiz cookie va JWT autentifikatsiyasi.
* Barcha maxfiy kalitlar va muhit o‘zgaruvchilari server tomonda saqlanadi.
